# 鼠大 SUDA · 15页可编辑 HTML

下载后使用 Windows 的 Edge 或 Chrome 打开 HTML 文件，图片和完整字体均已内嵌，不需要网络。

## 像 PPT 一样编辑

1. 按 **E** 或点击“编辑”，进入带页面列表与属性栏的编辑界面。
2. **双击文字**直接输入；也可在右侧修改内容、字号、颜色和对齐。标题默认为 ChillRoundM，正文为 ZhiyiMaru，小字宋体优先。
3. **双击图片**替换；拖动对象移动位置，拖动边框手柄缩放。右侧可调整取景、放大及完整显示/裁切。图片文件也可直接拖到页面或现有图片框。
4. 图表里的文字双击后可在右侧修改；图表整体可移动、缩放。曲线和坐标为 SVG，不连接 Excel 工作簿。
5. 工具栏支持新增文字/图片、复制、删除、前后层级，以及撤销重做。
6. **保存 HTML / Ctrl+S** 导出带修改的新文件。请使用这个按钮保留与分享；浏览器本机自动暂存不是文件保存。

演示模式：方向键、空格、PageUp/PageDown 翻页；O 打开目录；N 查看逐页讲稿和来源；F 全屏；手机左右滑动。画布固定16:9，手机不改变版式。打印支持每页16:9，建议开启背景图形。

## 数据口径

日本产品价格为用户指定日元价格，不换算人民币；BOCCO主表为原版31,900日元。BOCCO emo的52,800日元标价及所提供33,000日元活动价单列脚注，不与原版混淆；并非实时抓价保证。

鼠大商业数字统一为“课程策划假设 / 待验证”：39元制造成本；49元总变动成本；99元售价；1,000只试销；30,000元固定投入；600只盈亏平衡；99,000元销售额；20,000元预计利润；ROI 66.7%。制造成本包含于49元，不另加一次。ROI=预计利润/固定投入，非会计净利润率。预算细分、排期及KPI也是课程假设，不表示实际结果。
