# 鼠大 / SUDA · 产品策划

打开 `鼠大-SUDA-产品策划.html` 即可离线演示，无须安装依赖。30页，1920×1080固定画布；图片、中文字体、CSS及JavaScript均已内嵌。

- ← / →、空格、PageUp / PageDown：翻页；手机左右滑动。
- O：页面目录；N：逐页讲稿；F：全屏；Esc：关闭目录或讲稿。
- E：编辑文本；Ctrl / Command + S：导出修改后的HTML。普通正文编辑会暂存于当前浏览器。
- 第03页按要求完全留白，供插入汇报人图片；可在HTML对应 `SLIDE 03` 的 `.content` 中加入图片。
- 页面底部中央悬停可显示控制栏。
- 浏览器打印支持逐页16:9输出；建议使用背景图形选项。

## 内容边界

鼠大图片为AI概念可视化，不是实物或性能证明。机构、用户画像、优先级与商业计划已标识为提案或待验证假设。未编造销量、成本、用户调研结果或量产数据。

品牌行为与产品图已读取并核对Yukai Engineering官方产品总览：https://www.ux-xu.com/products/ 。其独立产品站点部分存在脚本渲染或失效入口；官方总览为本稿主要事实来源。品牌产品图片版权归Yukai Engineering等原权利人。本稿用于课程研究，商业用途需另行处理图片及校园IP授权。

## 可编辑材料

- `讲解稿.md`：逐页讲解与验证边界。
- `build.py`：页面生成源程序；`image-map.json`为本机原始图像路径。
- `assets/`：官方产品研究图片与字体。鼠大原始图片保存在 `/workspace/generated_images/`。
- `checks/`：桌面、手机与页面总览的截图验证。

Frontend Slides技能源：`/workspace/frontend-slides/SKILL.md`。采用用户已指定的封面方向，直接展开完整稿，不再要求重新选模板。

网络配置草稿已添加Yukai相关官方域名以读取资料；这与HTML交付无关。如需将此网络配置保留给后续云任务，请在环境设置中审阅保存后发布。当前HTML不依赖这些网络连接。
